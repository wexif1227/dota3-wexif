# RIFT — Dota3 community alpha

Unity **2022.3.20f1** · основной клиент **Windows x64** · C# authoritative WebSocket server. Работа над Android временно отложена.

Ранняя играбельная версия MOBA по мотивам Dota. В локальном проекте подключены шесть моделей из установленной Dota 2 с текстурами, скелетами и анимациями. Локальные файлы находятся в `Assets/Arena/Resources/DotaImported` и исключены из Git. Для проекта без этих файлов предусмотрены собственные процедурные модели. Иконки предметов и способностей нарисованы через imagegen. Баланс и часть механик пока упрощены; границы реализации описаны в [STATUS.md](STATUS.md).

## Запуск в Unity

1. Открыть папку, в которой находятся `Assets`, `Packages`, `ProjectSettings`, через Unity Hub с версией **2022.3.20f1**.
2. Дождаться завершения импорта. Меню **RIFT → Prepare project** создаёт сцену `Assets/Arena/Scenes/Arena.unity` и настройки сборки. Исходная `SampleScene` сохранена.
3. Открыть `Arena.unity` и нажать Play. Приложение создаётся автоматически; скрипты вручную прикреплять не требуется.
4. Выбрать героя, формат 1×1 / 2×2 / 5×5, сторону и сложность ботов.
5. **Тренировка с ботами** запускает локальный матч без сервера. **Онлайн → Создать комнату** выдаёт шестизначный код. Другие игроки вводят этот код через **Войти по коду**. Лидер нажимает **Начать матч**; свободные места занимают боты.

## Готовая Windows-сборка

Запускайте `Builds/Windows/Rift.exe`. Переносить нужно **всю папку Windows**, включая `Rift_Data`, `MonoBleedingEdge` и DLL рядом с exe. Unity для запуска готового клиента не требуется.

В настройках доступны громкость, три уровня графики, скорость камеры, быстрое применение и оконный/полноэкранный режим. При обычном применении нажмите клавишу способности, затем ЛКМ по цели. При быстром применении цель выбирается в позиции курсора сразу при нажатии клавиши.

## Управление

| Действие | ПК |
|---|---|
| Выбор героя / просмотр юнита | ЛКМ по модели или полоске HP; рамка ЛКМ выбирает своего героя |
| Движение, атака, добивание | ПКМ; удержание ПКМ обновляет точку движения 10 раз в секунду |
| Следование за союзником | ПКМ по союзному юниту; крипа ниже 50% HP можно добить |
| Способности | Q W E D F R; обычные герои используют Q W E R |
| Изучить способность | Ctrl + клавиша или `+` над способностью |
| Предметы | 1–6 |
| Магазин / таланты | B / T |
| Остановиться | S |
| Удерживать позицию и атаковать в радиусе | H |
| Атака / движение с атакой | A, затем ЛКМ по цели / земле |
| Выбрать героя и вернуть камеру | F1 / пробел; удерживать для слежения |
| Камера / масштаб | Стрелки, края экрана или зажатая средняя кнопка / колесо |
| Миникарта | ЛКМ — камера; ПКМ — движение; при выбранном TP — цель телепорта |
| Отмена / меню | Escape |

Android: экспериментальное сенсорное управление сохранено в исходниках. Проверка на физическом телефоне и дальнейшая адаптация отложены в пользу Windows.

Удар состоит из подготовки, попадания и завершения. Команда движения или S отменяет подготовку до урона; после попадания завершение можно прервать, но это не ускоряет следующий удар. У дальних героев снаряд летит к цели. Автоповтор ПКМ включён по умолчанию и переключается в настройках.

## Сервер локально

Требуется .NET SDK 8. В терминале из корня проекта:

```powershell
dotnet run --project Server/RiftServer.csproj
```

В настройках игры: `ws://127.0.0.1:10000/ws`. Для другого компьютера в одной сети нужен LAN-адрес сервера вместо `127.0.0.1`.

Развёрнутый интернет-сервер уже выбран по умолчанию: `wss://dota3-wexif.onrender.com/ws`. [Проверка состояния сервера](https://dota3-wexif.onrender.com/health).

## Render, бесплатный тариф

Репозиторий: https://github.com/wexif1227/dota3-wexif

| Поле Render | Значение |
|---|---|
| Service type | Web Service |
| Language / runtime | Docker |
| Branch | main |
| Region | Frankfurt |
| Root Directory | пусто |
| Dockerfile Path | `./Dockerfile` |
| Docker Build Context | `.` |
| Instance type | Free |
| Health Check Path | `/health` |

Build Command и Start Command вручную не нужны: их задаёт Dockerfile. `render.yaml` также описывает сервис для Blueprint. Сервер читает `PORT` (по умолчанию 10000) и `MAX_ROOMS` (по умолчанию 8).

Render Free предназначен для тестирования: сервис засыпает после 15 минут без входящего трафика; первый запрос может ждать около минуты. Активные матчи хранятся в памяти и теряются при перезапуске сервиса. Есть лимиты трафика и часов. Смотрите [условия Free](https://render.com/docs/free) и [WebSocket](https://render.com/docs/websocket). Клиент выполняет heartbeat и пытается восстановить существующую сессию; после перезапуска сервера нужно создать новую комнату.

## Сборки

- **RIFT → Build Windows**: `Builds/Windows/Rift.exe`; распространять всю папку Windows.
- **RIFT → Build Android APK**: `Builds/Android/Rift.apk`. Требуется Android Build Support с SDK, NDK и OpenJDK, установленный через Unity Hub для версии 2022.3.20f1. IL2CPP, ARM64 + ARMv7, Android 6+.
- APK подписывается отладочным ключом Unity. Для публикации в магазине нужен отдельный процесс выпуска и собственный ключ.

## Проверки

```powershell
dotnet run --project Tests/CoreTests.csproj -c Release
dotnet build Server/RiftServer.csproj -c Release
# при запущенном сервере, Node.js 22+
node Tests/network.mjs
# проверка развёрнутого сервера
node Tests/network.mjs wss://<имя-сервиса>.onrender.com/ws
```

Тесты проверяют команды и ресурсы, шесть наборов способностей, режимы, рецепты, добивание, выкуп, курьера, завершение матча, десятиминутную симуляцию, комнату, серверный обзор и переподключение. Сетевая проверка создаёт короткий тестовый матч; пустые комнаты удаляются через пять минут.

## Устройство проекта

- `Assets/Arena/Core`: чистый C#, общая симуляция для Unity и сервера.
- `Assets/Arena/Client`: 3D-карта, модели, UI, управление, соединение.
- `Assets/Arena/Editor`: подготовка сцены, сборки, автоматическая проверка Play Mode.
- `Server`: ASP.NET Core, WebSocket-комнаты, серверная симуляция 20 Hz, снимки 10 Hz.
- `Tests`: проверки без сторонних тестовых пакетов.

Клиент отправляет намерения (двигаться, применить, купить), а сервер проверяет золото, ману, кулдауны, уровень и видимость. Скрытые враги не включаются в снимок команды. Отключившегося игрока временно ведёт бот; секретный токен позволяет вернуть своего героя.

Названия Dota и героев принадлежат их правообладателям. Проект не является продуктом Valve и не заявляет о такой связи.
